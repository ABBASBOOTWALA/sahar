      What these terms mean
      Documented origin
      The year the concept actually originated, established outside this data by a specific publication or event. Shannon's paper for information theory, 1948. This is the answer the instrument is being tested against, not something it computed.
      Detected onset
      The first year the phrase reaches the detector's threshold in the literature and then stays there. This is the instrument's own answer.
      Signed error
      Detected minus documented. Positive means the instrument read the concept as arriving later than it did, negative means earlier. The sign matters more than the size: a one-directional error is a bias that can be corrected, scatter cannot.
      Documents
      How many works in OpenAlex match the phrase, after excluding the journals this project studies so that nothing is counted on both sides.
      The detector
      Twelve documents in a year, sustained for three consecutive years. Sustained, because a single-year spike in a corpus this size is usually a cataloguing artefact. Twelve, because the setting is a trade: stricter is more accurate but discards more cases, which is the curve shown below.
      Polysemy screen
      Catches phrases that already meant something else. Holography collides with holograph, a probate term for a handwritten will that predates the physics by centuries, so the phrase appears in the record long before Gabor. The screen compares how often the phrase is used before the origin against after it.
      Admissibility screen
      Asks whether a concept can fairly test this detector at all. It runs the detector over the years before the origin. If it fires there, it is firing on something that cannot be the concept, so that case cannot be used to judge it. This exists because a screen validated against one detector gave no protection to another, and a concept carrying 140 mis-dated records was read twenty years early.
      Usable
      Passed both screens and produced a reading. Only these count toward the error figures.
      Standing evidence

      Coverage against accuracy

      A stricter detector is more accurate because it throws away the cases that would expose it. Accuracy bought that way is not accuracy.
